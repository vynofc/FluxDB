# FluxDB

Quick: Installer ReadMe for DEVs: [Installer README.md](https://github.com/vynofc/FluxDB/tree/main/Installer/README.md)

FluxDB ist ein leistungsstarker, WPF-basierter Dateimanager und Indizierungs-Service für Windows. Er ermöglicht es Benutzern, ihre Dateien effizient zu verwalten, zu indizieren und mit Tags zu versehen, um sie blitzschnell wiederzufinden.

## ✨ Funktionen

- **Indizierung:** Scannen und Indizieren von lokalen Ordnern für eine extrem schnelle Suche.
- **Dateiverwaltung:** Standardoperationen wie Kopieren, Ausschneiden, Einfügen, Löschen und Umbenennen direkt in der App.
- **Tagging-System:** Versehen Sie Dateien mit individuellen Tags, um sie unabhängig von ihrer Ordnerstruktur zu organisieren.
- **Erweiterte Suche:** Blitzschnelles Finden von Dateien basierend auf Name, Erweiterung oder Tags.
- **Dateivorschau:** Integrierte Vorschau für Bilder inklusive Zoom-Funktionalität.
- **Export-Funktion:** Exportieren Sie Ihren Index für Backups oder zur weiteren Analyse.
- **Lizenzverwaltung:** Integriertes System zur Verwaltung von Softwarelizenzen.
- **Logging:** Integrierter Log-Viewer zur Überwachung von Indizierungsprozessen und Systemmeldungen.

## 🛠 Technologien

FluxDB wurde mit modernen .NET-Technologien entwickelt:

- **Sprache:** C# 7.3
- **Framework:** WPF (Windows Presentation Foundation) auf .NET Framework 4.7.2
- **Datenbank:** SQLite (für effiziente Metadatenspeicherung)
- **Bibliotheken:**
  - `Newtonsoft.Json`: Für Konfigurations- und Exportdateien.
  - `System.Data.SQLite`: Für Datenbankinteraktionen.

## 📖 Nutzung

1. **Ordner wählen:** Klicken Sie auf "Ordner wählen", um einen neuen Speicherort zu öffnen.
2. **Indizierung starten:** Falls der Ordner noch nicht indiziert ist, bietet FluxDB an, diesen zu scannen.
3. **Tags hinzufügen:** Wählen Sie eine Datei aus und fügen Sie im rechten Seitenpanel Tags hinzu.
4. **Suchen:** Nutzen Sie die Suchleiste oben, um sofort Ergebnisse aus Ihrem Index zu erhalten.
